# Nerio

Daily Mental Training

Nerio is a native iOS app that provides short daily exercises to train mental
arithmetic, calendar calculation, memory, logic, and patterns — the same way
physical exercise trains the body.

## Status

Early development.

## Tech Stack

Swift · SwiftUI · Native Apple frameworks

## Build & Run

1. Open `nerio.xcodeproj` in Xcode
2. Select an iOS simulator
3. Press **Cmd+R**
